\# Modelo de datos - Aura Viva



\## Tabla perfumes



| Campo | Que es | Ejemplo |

| --- | --- | --- |

| nombre del perfume | Nombre del perfume | 212 VIP |

| marca | Marca del perfume | Carolina Herrera |

| tipo de fragancia | árabe, tradicional |

| mL | Tamano del frasco | 100 |

| cantidad | Cuantos hay en inventario | 5 |

| precio | Precio de venta | 35000 |



\## Reglas



\- No puede haber dos perfumes con el mismo nombre y los mismos mL.

\- La cantidad no puede ser negativa.

\- El precio es en pesos colombianos.

\- Cuando la cantidad es 0, el perfume esta agotado.
